# Work Hub

Work Hub is an offline-ready workspace for managing clients, invoices, and time entries.

## Run locally

- `bun install`
- `bun run dev`

## Production build

- `bun run lint`
- `bun run build`
- `bun run preview`

The production build includes a web app manifest and a service worker that precaches the app and its bundled assets. Open the deployed app while online once and allow the service worker to finish installing; later visits can load and work offline. Service workers require HTTPS in production (localhost is also supported). The Vite development server is not offline-cached.

## Publish and install on computers and phones

1. Keep the whole project folder (including `package.json`, `src`, and `public`) or push it to a private GitHub repository. The `dist` folder is generated by `bun run build`; it is the deployable website, not the editable source project.
2. Build with `bun run build`, then publish the contents of `dist` to a static web host with HTTPS, such as Netlify, Vercel, or Cloudflare Pages. For GitHub Pages, configure the Vite `base` path to match the repository URL before building.
3. Visit the HTTPS address once while online so the app can install its offline cache.
4. On desktop Chrome or Edge, use the install icon in the address bar or the browser menu's **Install Work Hub** option. On Android Chrome, open the menu and choose **Install app** or **Add to Home screen**. On iPhone/iPad, open the address in Safari, tap **Share**, then **Add to Home Screen**.

This installs the web app, not a native Windows/macOS/Android/iOS package. Each device has its own local workspace data; clients and invoices do not automatically sync between devices. Cross-device synchronization needs a hosted database and user authentication.

## Your data

Client records, invoices, time entries, the active timer, profile, and theme are saved in browser storage on this device and origin. They remain available offline, but are not synced to other devices or backed up to a server. Clearing this site's browser data or using private browsing can remove the records. Keep the browser profile and site data if you need to retain them.
